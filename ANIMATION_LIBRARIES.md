# Animation libraries

## Motion (`motion`)

Gestures, layout, and enter/exit next to the markup. Import from `motion/react`.

Use it for buttons, shared elements, drag, and everyday UI. A long labeled sequence is easier in GSAP.

## GSAP (`gsap`, `@gsap/react`)

Timelines, ScrollTrigger, Flip, Draggable, DrawSVG, and SplitText. Register plugins once in `src/animations/gsap/register.ts`. Create tweens in `useGSAP` so they revert on unmount.

Use it for scroll, SVG, and coordinated sequences. A three-percent hover is less code in Motion.

The public package includes the plugins. This app configures preset demos. It is not a general visual animation builder.

## React Spring (`@react-spring/web`)

Springs that can be interrupted. `useSpring`, `useTrail`, and `useTransition`. Stiffness, damping, and mass are the controls that matter.

Use it when the target moves before the previous motion finishes, especially pointer follow.

## Lottie (`lottie-react`)

Plays JSON. The clips in `src/animations/lottie/assets` are original and generated by `src/animations/lottie/build-clips.mjs`. Runtime controls are speed, direction, and loop.

Use it for a loader or a success mark a designer already drew. Do not use it for a list.

## AutoAnimate (`@formkit/auto-animate`)

One ref on the parent. Children animate when they are added, removed, or reordered. There is no playhead.

Use it for lists and simple accordions. Do not use it for a fade tween.
